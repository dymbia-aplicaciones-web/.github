# SumaqAgro

SumaqAgro is an enterprise precision agriculture web platform developed by **Dymbia**, a technology startup focused on building innovative digital solutions for the agricultural sector. The platform is designed for small and medium-sized farmers, agricultural cooperatives, and technical advisors in Peru, with a particular emphasis on Andean potato cultivation and specialty coffee production.

SumaqAgro integrates open satellite imagery, lot-level financial management, and digital quality certification into a unified web application based on a Service-Oriented Architecture (SOA). This enables data-driven agricultural decision-making without requiring physical ground sensors.

---

## Tech Stack

### Backend (Web Services & RESTful APIs)
* **C# / .NET Core**: Core programming language and framework for building scalable RESTful Web Services.
* **ASP.NET Core Web API**: Framework for constructing RESTful endpoints following Clean Architecture and Domain-Driven Design (DDD) principles.
* **Entity Framework Core (EF Core)**: Object-Relational Mapper (ORM) used for data persistence, database migrations, Data Annotations, and Fluent API configurations.
* **SQL Server**: Relational database management system for structured domain data storage.
* **Swagger / OpenAPI**: API documentation and interactive testing interface.

### Frontend (Web Client Applications)
* **Vue.js 3**: Progressive JavaScript/TypeScript framework for building dynamic, reactive user interfaces.
* **PrimeVue / Material Design**: Accessible UI component libraries for responsive layout design and web accessibility (a11y).
* **Pinia**: Centralized state management for frontend client interactions.
* **Vue Router**: Client-side single-page application (SPA) routing.
* **Axios / Web Services Client**: Asynchronous HTTP client for integrating Vue.js with backend RESTful APIs to execute full CRUD operations.
* **Vue i18n**: Multi-language support and internationalization framework.

### AI & Cloud Integration
* **Microsoft.Extensions.AI**: Integration of AI libraries for real-time data suggestions and assisted feature implementations.

## Core Features

* **Satellite Health & Moisture Monitoring**: Visualization of vegetation (NDVI) and water (NDWI) indices using integrated satellite imagery tools to monitor crop conditions, detect agricultural stress, and support preventive decision-making.
* **Lot-Level Cost Accounting Engine**: Management of operational expenses at the agricultural lot level, featuring automated financial break-even calculations and production cost tracking.
* **Digital Harvest Quality Scoring & Certification**: Generation of digital quality certificates for potato grading and specialty coffee cup profiles, supported by dynamic QR codes for verification and full traceability.
